01About

Bohdan

Python developer from Zakarpattia, now based in Lviv, Ukraine. Four years of backend work — Django and FastAPI services, REST APIs, data pipelines and parsers — with React on the front when a project needs one.

These days a good share of that Python goes into Odoo: custom ERP modules running real shops, kitchens and a production floor. Same language, same ORM instincts, just a far more opinionated framework wrapped around them.

I like the problems where third-party APIs, messy business processes and a clear interface all have to meet in one place.
